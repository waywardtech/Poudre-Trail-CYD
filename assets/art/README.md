# Art Assets

Place BMP files here for CYD rendering.

Suggested structure:
- janis.bmp
- friday.bmp
- mason.bmp
- virginia.bmp
- locations/
  - laporte.bmp
  - council_tree.bmp
  - virginia_dale.bmp
  - mason_claim.bmp

Notes:
- Use 24-bit uncompressed BMP
- Keep resolution modest (e.g., 96x72 or similar) for performance
